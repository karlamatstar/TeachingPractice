# 실습 상태

- 상태: **모니터링 구조 학습 완료**
- 강의 제목: IT 운영·모니터링 실무(1~4)
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-06-29 \~ 2026-07-02 · 23\~26일차
- 학습 수준: 중급

## 실습 요약

FastAPI 로그·메트릭·테스트·Prometheus·부하 측정을 연결하는 실습입니다.

## 이 단계의 완료 기준

- FastAPI Agent 요청이 로그와 Prometheus 메트릭으로 기록되고 대시보드가 이를 조회하는 구조를 설명할 수 있습니다.
- 기능 테스트와 k6 부하 결과가 JSON·로그·성능 판정 보고서로 `_OUTPUT`에 저장되면 완료입니다.

## 후속 실습과의 관계

`40_AI_챗봇_품질관리_최종프로젝트`는 이 모니터링·테스트 개념을 챗봇 품질평가와 대시보드가 있는 단계형 프로젝트에 적용합니다.

## 이어서 학습하면 좋은 내용

- 오류율·지연시간·처리량 임계값을 정하고 성능 판정 보고서와 일치시키도록 자동화합니다.
- API 중단과 느린 응답을 재현해 로그·메트릭·사용자 오류 메시지가 함께 남는지 확인합니다.
