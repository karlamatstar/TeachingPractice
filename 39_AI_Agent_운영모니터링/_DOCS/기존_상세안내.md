# AI Agent 운영 모니터링

FastAPI 서비스, 로그, Prometheus 지표, Streamlit 화면과 k6 성능 결과를 연결합니다.

```powershell
pip install -r requirements.txt
uvicorn src.app:app --reload
streamlit run src/streamlit_app.py
```

- `src`: API와 대시보드 코드
- `tests`: 기능 테스트 입력과 실행 코드
- `performance`: k6 시나리오와 보고서 생성 코드
- `_OUTPUT`: 로그, 기능 테스트 결과, 성능 결과
