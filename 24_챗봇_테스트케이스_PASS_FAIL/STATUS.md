# 실습 상태

- 상태: **비교 실습 완료**
- 강의 제목: 테스트 케이스 도출 / 테스트 실행 프로세스
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-06-12–06-15 · 12–13일차
- 학습 수준: 초급

## 실습 요약

동일 챗봇의 실패·통과 변형을 같은 테스트로 실행하고 결과 차이를 확인하는 실습입니다.

## 이 단계의 완료 기준

- 동일한 StyleMall 챗봇 테스트를 `fail`과 `pass` 구현에 실행해 응답·평가 로직 차이를 비교할 수 있습니다.
- 실패 원인과 수정 후 통과 근거가 Markdown·DOCX 보고서와 추출 텍스트에 일관되게 남아 있으면 완료입니다.

## 후속 실습과의 관계

하나의 결함을 실패본과 통과본으로 비교하는 완결형 QA 실습입니다. 테스트 케이스 생성 실습은 별도 데이터 제작 과제이므로 연결하지 않습니다.

## 이어서 학습하면 좋은 내용

- 두 구현의 차이를 코드 변경, 기대 효과와 회귀 위험으로 나눠 기록합니다.
- 통과본에도 경계값·오류 응답·대화 맥락 테스트를 추가해 과적합을 점검합니다.

## 폴더 구성

- `README.md`: 실습 개요와 실행 안내
- `src`: 코드와 단계별 실습 자료
- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
