# 실습 상태

- 상태: **기초 단계 학습 완료**
- 강의 제목: AI Agent를 이해하면 테스트가 쉬워진다
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-06-05~06-08 · 7~8일차
- 학습 수준: 입문

## 실습 요약

단일 Agent의 지시·도구·모델 호출 구조를 가장 작은 코드로 확인하는 실습입니다.

## 이 단계의 완료 기준

- 사용자 요청에서 날씨 또는 장소 검색 도구와 인자를 고르는 첫 번째 모델 호출을 설명할 수 있습니다.
- 선택된 함수를 실행한 결과를 다시 모델에 전달해 최종 답변을 만드는 두 단계 Agent 흐름을 추적하면 완료입니다.

## 후속 실습과의 관계

`13_함수호출_도구연동_Agent`는 이 폴더의 수동 도구 선택·실행 흐름을 시간·주식 도구와 화면까지 확장하는 직접 후속 실습입니다.

## 이어서 학습하면 좋은 내용

- 도구가 필요 없는 질문과 인자가 누락된 질문을 넣어 분기 처리를 확인합니다.
- 도구 실행 실패를 모델에 다시 전달할 때 사용자가 이해할 수 있는 오류 답변을 설계합니다.
