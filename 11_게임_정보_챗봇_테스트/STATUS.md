# 실습 상태

- 상태: **단계 실습 완료**
- 강의 제목: 블랙박스 테스트 기법
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-06-04~06-05 · 6~7일차
- 학습 수준: 초급

## 실습 요약

게임 정보 챗봇의 테스트 케이스 실행, 결과 저장, Judge 평가로 이어지는 단계별 실습입니다.

## 이 단계의 완료 기준

- JSONL 테스트 케이스를 읽고 필수 필드를 검증한 뒤 게임 정보 질문을 챗봇에 순서대로 전달하는 흐름을 확인할 수 있습니다.
- 챗봇 답변과 Judge 결과가 JSON·Excel·로그로 저장되고, 정상·엣지·부정 사례를 결과 파일에서 구분할 수 있으면 완료입니다.

## 후속 실습과의 관계

게임 정보 챗봇을 대상으로 한 블랙박스 테스트와 결과 저장까지 완결된 실습입니다. Agent 기초구조 폴더와 직접 공유되는 구현은 없습니다.

## 이어서 학습하면 좋은 내용

- 깨진 한글 인코딩을 복구한 뒤 기존 50개 질문의 기대 결과를 다시 검토합니다.
- 최신 게임 확률처럼 시점에 따라 변하는 정보는 기준일과 출처를 테스트 케이스에 추가합니다.

## 폴더 구성

- `README.md`: 실습 개요와 실행 안내
- `src`: 코드와 단계별 실습 자료
- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
