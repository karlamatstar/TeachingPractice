# 실습 상태

- 상태: **독립 실습 완료**
- 강의 제목: 취업에 필요한 마케팅 포트폴리오 구축
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-06-04 · 6일차
- 학습 수준: 입문

## 실습 요약

PRD를 기준으로 단일 페이지와 확장형 포트폴리오 웹 화면을 구현하는 실습입니다.

## 이 단계의 완료 기준

- 두 PRD의 요구사항이 단일 페이지와 확장형 페이지의 섹션·콘텐츠·동작에 각각 반영됐는지 대응시킬 수 있습니다.
- 브라우저에서 내비게이션, 모달, 토스트와 주요 링크를 확인하고 화면이 깨지지 않으면 완료입니다.

## 후속 실습과의 관계

마케팅 포트폴리오라는 하나의 웹 결과물로 완결됩니다. 청첩장 실습은 같은 웹 기술을 쓰지만 별개의 요구사항과 자산으로 구성됩니다.

## 이어서 학습하면 좋은 내용

- PRD 항목별 구현 여부를 체크리스트로 만들어 누락을 점검합니다.
- 모바일·태블릿·데스크톱에서 CTA와 모달 사용성을 비교합니다.
