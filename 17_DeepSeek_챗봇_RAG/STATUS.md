# 실습 상태

- 상태: **기초 단계 학습 완료**
- 강의 제목: 대체 LLM 및 RAG 확장 실습
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 학습 흐름: 대체 LLM 기반 RAG
- 학습 수준: 중급

## 실습 요약

DeepSeek 기반 단순 챗봇과 검색 증강 답변 구조를 비교하는 실습입니다.

## 이 단계의 완료 기준

- DeepSeek 단순 챗봇과 문서 검색을 거치는 RAG 챗봇의 응답 경로를 비교할 수 있습니다.
- 질의 확장, Chroma 검색 상위 문서와 스트리밍 답변이 연결되는 과정을 추적하면 완료입니다.

## 후속 실습과의 관계

대체 LLM을 RAG에 적용해 보는 독립 비교 실습입니다. LangGraph 메모리·도구 실습과 직접 공유하는 상태 그래프는 없습니다.

## 이어서 학습하면 좋은 내용

- 같은 질문을 일반 챗봇과 RAG에 넣어 근거성·환각 차이를 기록합니다.
- DeepSeek 생성 모델과 OpenAI 임베딩을 함께 쓰는 구조의 비용·의존성을 정리합니다.
