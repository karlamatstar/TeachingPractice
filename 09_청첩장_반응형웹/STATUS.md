# 실습 상태

- 상태: **독립 실습 완료**
- 강의 제목: 반응형 정적 웹 제작 실습
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 학습 흐름: 반응형 웹 제작 기초
- 학습 수준: 입문

## 실습 요약

HTML과 이미지 자산으로 반응형 청첩장 페이지를 구성하는 기초 웹 실습입니다.

## 이 단계의 완료 기준

- `src/index.html`과 이미지 자산이 로컬 브라우저에서 누락 없이 표시되는지 확인할 수 있습니다.
- 초대 문구·일정·장소·연락 정보가 화면 크기에 따라 읽기 좋은 순서와 간격으로 배치되면 완료입니다.

## 후속 실습과의 관계

정적 반응형 청첩장 한 페이지로 마무리되는 독립 실습입니다. Git/GitHub ERP 협업 자료와는 직접적인 후속 관계가 없습니다.

## 이어서 학습하면 좋은 내용

- 작은 모바일 화면과 넓은 데스크톱 화면에서 텍스트 겹침과 이미지 잘림을 검사합니다.
- 지도·전화·공유 기능을 추가한다면 실제 링크 동작을 별도 체크리스트로 관리합니다.

## 폴더 구성

- `README.md`: 실습 개요와 실행 안내
- `src`: 코드와 단계별 실습 자료
- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
