# 실습 상태

- 상태: **자동화 구조 학습 완료**
- 강의 제목: AI Agent 품질 프레임워크 테스트 자동화
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-06-09~06-10 · 9~10일차
- 학습 수준: 중급

## 실습 요약

API Judge와 UI E2E를 pytest로 검증하고 결함 보고서 증거를 생성하는 실습입니다.

## 이 단계의 완료 기준

- FastAPI `/chat` 응답을 매개변수화된 pytest와 LLM Judge로 검증하는 테스트 구조를 확인할 수 있습니다.
- UI E2E 테스트가 화면 증거, 로그와 HTML 결함 보고서를 `_OUTPUT`에 남기는 과정을 확인하면 완료입니다.

## 후속 실습과의 관계

RAIT 개념을 API와 UI 자동화까지 구현한 완결 단계입니다. 다음 챗봇 PASS/FAIL 비교는 다른 애플리케이션을 사용하므로 별도 실습으로 봅니다.

## 이어서 학습하면 좋은 내용

- Judge를 사용할 수 없을 때 테스트를 실패·건너뜀·N/A 중 무엇으로 처리할지 규칙화합니다.
- 결함 보고서에 테스트 ID, 재현 절차와 화면 증거 경로를 자동 연결합니다.

## 폴더 구성

- `README.md`: 실습 개요와 실행 안내
- `src`: 코드와 단계별 실습 자료
- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
