# 실습 상태

- 상태: **기초 단계 학습 완료**
- 강의 제목: LangGraph 상태·도구 확장 실습
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 학습 흐름: LangGraph 상태·메모리·도구 활용
- 학습 수준: 중급

## 실습 요약

상태 그래프, 대화 메모리와 도구 노드를 연결하는 실습입니다.

## 이 단계의 완료 기준

- `StateGraph`의 상태, 시작·종료 엣지와 생성 노드가 메시지를 갱신하는 방식을 설명할 수 있습니다.
- 대화 메모리로 이전 메시지를 유지하는 흐름과 도구 노드로 분기하는 흐름을 각각 확인하면 완료입니다.

## 후속 실습과의 관계

`19_LangGraph_RAG`는 여기서 익힌 상태 그래프에 문서 검색과 근거 기반 응답 노드를 배치하는 직접 후속 실습입니다.

## 이어서 학습하면 좋은 내용

- 동일한 대화 ID와 새로운 대화 ID에서 메모리가 유지·분리되는지 비교합니다.
- 도구 호출 성공·실패·미호출 경로를 그래프로 표시하고 각 상태 값을 기록합니다.
