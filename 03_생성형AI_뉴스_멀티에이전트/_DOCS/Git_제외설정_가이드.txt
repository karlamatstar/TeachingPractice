======================================
프로젝트 복사 후 다른 VS Code에서 사용하는 절차
======================================

1단계: 파일 복사
.venv 폴더는 제외하고 나머지만 복사하세요


2단계:  VS Code에서 폴더 열기
-파일 → 폴더 열기 → 복사한 폴더 선택

3단계: 가상환경 새로 생성
터미널에서 실행:    .venv\Scripts\activate

4단계: 패키지 설치
pip install langchain langchain-openai langgraph python-dotenv


5단계: .env 파일 확인
.env 파일 확인(새로만들기)
.env 파일 안의 API 키가 올바른지 확인:  OPENAI_API_KEY=sk-xxxxxxxx

6단계: 실행 테스트  : python src/main.py

핵심 요약은  .venv만 빼고 복사 → 새 가상환경 생성 → 패키지 재설치 → 실행
