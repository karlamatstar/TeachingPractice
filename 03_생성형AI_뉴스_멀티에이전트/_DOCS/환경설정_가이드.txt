.env 파일 만들기

1. 프로젝트 최상위에서 다음 명령을 실행합니다.

   notepad .env

2. 열린 파일에 본인의 API 키를 입력합니다.

   OPENAI_API_KEY=your-openai-api-key

   등호 앞뒤에 공백을 넣거나 전체 값을 따옴표로 감싸지 않는 것을 권장합니다.
   실제 API 키가 든 .env 파일은 Git에 포함하지 않습니다.

3. python-dotenv 설치 여부를 확인합니다.

   pip install python-dotenv

4. API를 사용하는 파일의 코드 상단에서 환경변수를 불러옵니다.

   import os
   from dotenv import load_dotenv

   load_dotenv()
   api_key = os.getenv("OPENAI_API_KEY")

5. 프로그램을 실행합니다.

   python src/main.py

추가 경고 해결: invalid escape sequence '\s'

- 잘못된 예: clean_text = re.sub("\s+", " ", clean_text).strip()
- 권장 예: clean_text = re.sub(r"\s+", " ", clean_text).strip()
