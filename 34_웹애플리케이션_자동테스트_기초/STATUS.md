# 실습 상태

- 상태: **웹 자동 테스트 기초 학습 완료**
- 강의 제목: AI를 활용한 웹 애플리케이션 구축
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-06-29 · 23일차
- 학습 수준: 중급

## 실습 요약

React·Cypress 프론트와 Node·Jest 백엔드의 기능·통합 테스트를 구성한 실습입니다.

## 이 단계의 완료 기준

- Todo 화면에서 입력과 추가 동작을 Cypress가 API Stub과 함께 검증하는 E2E 시나리오를 확인할 수 있습니다.
- 백엔드의 비밀번호 단위 테스트와 Todo API 조회·등록·입력 검증 통합 테스트를 실행하거나 각 기대값을 설명하면 완료입니다.

## 후속 실습과의 관계

React·Cypress와 Node·Jest를 사용한 웹 자동 테스트 기초로 독립 종료됩니다. 에듀봇 API는 별도의 Agent 기능 실습입니다.

## 이어서 학습하면 좋은 내용

- 프론트 E2E, API 통합, 함수 단위 테스트를 한 명령으로 실행하는 스크립트를 구성합니다.
- 테스트 결과와 실패 화면을 `_OUTPUT`에 저장하는 리포터를 추가합니다.

## 폴더 구성

- `README.md`: 실습 개요와 실행 안내
- `src`: 코드와 단계별 실습 자료
- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
