# 실습 상태

- 상태: **기초 단계 학습 완료**
- 강의 제목: 생성형 AI 멀티모달 확장 실습
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 학습 흐름: 생성형 AI 멀티모달 처리
- 학습 수준: 초급

## 실습 요약

이미지 설명·퀴즈와 텍스트 음성 변환을 통해 멀티모달 입출력을 확인하는 실습입니다.

## 이 단계의 완료 기준

- 이미지를 인코딩해 설명 또는 퀴즈 요청으로 전달하고, 재시도 횟수에 따라 응답을 처리하는 코드를 이해할 수 있습니다.
- 텍스트를 음성으로 변환하는 노트북의 입력 문장·음성 설정·생성 결과 흐름을 확인하면 완료입니다.

## 후속 실습과의 관계

이미지 이해와 TTS를 함께 살펴보는 독립 멀티모달 실습이며, 웹 포트폴리오 제작과 직접 연결되지 않습니다.

## 이어서 학습하면 좋은 내용

- 해상도·언어·객체 수가 다른 이미지로 설명 정확도를 비교합니다.
- 같은 문장을 서로 다른 음성·속도로 생성해 청취 품질을 기록합니다.

## 폴더 구성

- `README.md`: 실습 개요와 실행 안내
- `src`: 코드와 단계별 실습 자료
- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
