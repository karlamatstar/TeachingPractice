# 실습 상태

- 상태: **산출물 생성 실습 완료**
- 강의 제목: 테스트 케이스 도출 / 루브릭 기반 Judge Prompt 설계
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-06-12 \~ 2026-06-18 · 12\~16일차
- 학습 수준: 초급

## 실습 요약

안전성·다중 도메인 테스트 케이스를 코드와 프롬프트로 생성해 엑셀로 정리하는 실습입니다.

## 이 단계의 완료 기준

- 정치·경제·사회·문화·일상 영역의 정상·엣지·부정 질문이 난이도와 안전성 주의사항을 포함하도록 구성됐는지 확인할 수 있습니다.
- 고정 데이터 생성과 DSPy 기반 생성 코드가 테스트 케이스를 Excel 형식으로 만드는 과정을 설명하면 완료입니다.

## 후속 실습과의 관계

생성한 질문·기대 결과·주의 요소는 `27_Few_shot_Judge_평가실습`처럼 루브릭 기반 실행기에 입력 데이터로 활용할 수 있습니다. 파일 자체가 자동 전달되지는 않으므로 연동 시 스키마 변환이 필요합니다.

## 이어서 학습하면 좋은 내용

- 중복·모순·시점 의존 질문을 자동 검사하는 데이터 검증 단계를 추가합니다.
- 생성 근거와 검토자를 열로 추가해 사람이 승인한 케이스만 실행 세트로 분리합니다.

## 폴더 구성

- `README.md`: 실습 개요와 실행 안내
- `src`: 코드와 단계별 실습 자료
- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
