# 실습 2: 다양한 도메인별 QA 테스트 프롬프트 예시 모음

이 문서는 QA 전문가가 AI의 검색/추천 엔진 품질을 평가하기 위해 사용할 수 있는 다양한 프롬프트 예시 모음입니다. 실무에서 바로 활용할 수 있도록 도메인, 품질 지표, 검색 형태, 난이도 등의 변수를 골고루 조합하여 작성되었습니다.

## 📌 프롬프트 기본 템플릿
```text
당신은 20년차 QA 전문가입니다.

[도메인] 기능에 대해
[품질지표] 기준으로
[검색형태] 검색을 활용한
[유형] 유형 테스트 케이스 [개수]개를 생성하세요.

난이도는 [난이도] 수준으로 작성하세요.
```

---

## 1. 커머스 / 쇼핑몰 도메인 (정확성 / Medium)
* **설정값**
  * [도메인] = 쇼핑몰 상품 검색
  * [품질지표] = 정확성
  * [검색형태] = 자연어 질문형 검색
  * [유형] = Happy
  * [개수] = 5
  * [난이도] = Medium

* **완성된 프롬프트**
```text
당신은 20년차 QA 전문가입니다.

쇼핑몰 상품 검색 기능에 대해
정확성 기준으로
자연어 질문형 검색을 활용한
Happy 유형 테스트 케이스 5개를 생성하세요.

난이도는 Medium 수준으로 작성하세요.
```
