# AWS 보안 장애복구 QA

AWS 보안 설정, S3, CloudWatch, 장애 재현·복구와 최종 QA 보고서를 정리한 실습입니다.

## 프로젝트별 학습 요약

- 해결하려던 문제: AWS 보안 설정과 장애복구 결과를 화면 확인에만 의존하지 않고 점검 항목과 증거가 대응되는 문서로 남겨야 합니다.
- 구현한 QA 흐름: 웹 서버 정상 화면을 기준 증거로 확보하고, 보안 설정 점검·장애 상황 확인·복구 결과 기록·최종 실습보고서 작성 순서로 자료를 구성합니다.
- 사용 기술: AWS IAM, EC2, S3, CloudWatch, 보안 점검표, 장애복구 결과표
- 확인한 결과: 정상 화면 이미지, 보안설정 점검표, 장애복구 결과표와 최종 실습보고서가 `_OUTPUT`에 보존되어 있습니다.
- 한계와 개선 방향: 실제 클라우드 리소스 상태는 저장소에 포함되지 않으므로, 계정 권한·리전·비용과 점검 시각을 증거별로 함께 기록할 수 있습니다.

## 학습 위치

- 강의 제목: Cloud Security Beginner(AWS) / AWS 환경 이해 및 도구
- 강의 순서: 2026-07-22 \~ 2026-07-27 · 39\~42일차
- 난이도: 고급

## 폴더 구성

- `src`: 실행 코드와 실습 단계
- `_DOCS`: 설명서, 계획서, 의존성 안내
- `_OUTPUT`: 실행 결과, 로그, 리포트와 과거 산출물
- `.env` 또는 `.env.example`: 필요한 경우 사용하는 환경변수 파일
- 설치 목록 파일: 프로젝트 루트 또는 `src` 하위의 `requirements.txt`, `package.json`, `pyproject.toml` 등

## 주요 실행 진입점

- 실행 진입점보다 문서·산출물 중심의 학습 묶음입니다.

세부 실행법이 원래 문서에 있었던 프로젝트는 `_DOCS/기존_상세안내.md`에 보존했습니다. 교재형 실습은 프로젝트 루트에서 `Set-Location src` 후 각 챕터의 코드를 실행하면 상대 경로를 유지할 수 있습니다.

## 실행 환경 안내

- 자료 열람에는 별도 모듈이 필요하지 않지만, 클라우드 실습 재현에는 권한이 부여된 AWS 계정·IAM 사용자와 EC2·S3·CloudWatch 사용 권한이 필요합니다.
- EC2 접속 방식에 따라 SSH 키 또는 AWS Systems Manager Session Manager 환경이 추가로 필요하며, 실제 AWS 리소스는 저장소에 포함되지 않습니다.

## 의존성 설치

- 별도 모듈 설치가 필요 없는 정적 자료 또는 브라우저 실습입니다.

## 산출물

새로 생성되는 로그·평가표·리포트는 `_OUTPUT`에 저장하도록 정리했습니다. 단계별 원본 코드는 `src/stage_*`에서 확인할 수 있습니다.
