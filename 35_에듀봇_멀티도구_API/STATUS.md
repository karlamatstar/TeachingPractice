# 실습 상태

- 상태: **기능 구조 학습 완료**
- 강의 제목: Agent API 서비스 확장 실습
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 학습 흐름: 웹 API와 Agent 결합
- 학습 수준: 중급

## 실습 요약

JavaScript 에듀봇의 출결·과정 안내 도구와 Python 쇼핑몰 고객센터 Agent·FastAPI 예제를 함께 비교하는 실습입니다.

## 이 단계의 완료 기준

- JavaScript 에듀봇이 출결 규정과 커리큘럼 도구를 골라 호출하고 일반 진로 상담은 모델이 직접 답하는 흐름을 확인할 수 있습니다.
- Python 예제의 배송 조회·주문 취소 Agent가 FastAPI `/api/chat`으로 노출되는 별도 구현과 JavaScript 구현의 차이를 설명하면 완료입니다.

## 후속 실습과의 관계

Python 고객센터 Agent와 JavaScript 에듀봇이라는 두 멀티도구 API 예제를 비교하는 범위에서 마무리됩니다. 응답 품질비교 실습과 자동으로 연결되는 테스트 데이터는 없습니다.

## 이어서 학습하면 좋은 내용

- 폴더명과 일치하도록 Python 예제도 교육 도메인으로 통일할지, 비교 예제로 유지할지 문서에 명시합니다.
- 도구가 필요한 질문·일반 상담·보안 우회 요청을 API 테스트 케이스로 추가합니다.

## 폴더 구성

- `README.md`: 실습 개요와 실행 안내
- `src`: 코드와 단계별 실습 자료
- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
