# 실습 상태

- 상태: **단계 실습 완료**
- 강의 제목: 멀티에이전트 콘텐츠 제작 실습
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 학습 흐름: 멀티에이전트 콘텐츠 제작
- 학습 수준: 중급

## 실습 요약

개요·집필·검토·자료 검색을 단계별 Agent로 나눈 책쓰기 워크플로 실습입니다.

## 이 단계의 완료 기준

- 단계별 코드에서 작성자, 콘텐츠 전략가, 감독자와 자료 검색 역할이 언제 추가되는지 비교할 수 있습니다.
- 상태 파일과 개요를 이어받아 목차 작성·본문 집필·검토가 그래프에서 반복되는 과정을 설명하면 완료입니다.

## 후속 실습과의 관계

책 한 권을 만드는 멀티에이전트 워크플로로 독립 완결됩니다. 로컬 LLM·임베딩 실습은 모델 실행 환경을 다루므로 직접 연결하지 않습니다.

## 이어서 학습하면 좋은 내용

- 각 단계에서 생성된 개요와 본문 버전을 보존해 Agent별 기여를 비교합니다.
- 감독자가 무한 반복하지 않도록 종료 조건과 최대 수정 횟수를 명시합니다.

## 폴더 구성

- `README.md`: 실습 개요와 실행 안내
- `src`: 코드와 단계별 실습 자료
- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
