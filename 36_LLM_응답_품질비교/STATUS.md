# 실습 상태

- 상태: **비교 평가 구조 학습 완료**
- 강의 제목: LLM 응답 비교 평가 실습
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 학습 흐름: LLM 응답 비교 평가
- 학습 수준: 중급

## 실습 요약

테스트 케이스와 모범 답변을 기준으로 여러 LLM 응답의 품질을 비교하는 실습입니다.

## 이 단계의 완료 기준

- 기준 모델 A와 비교 모델 B의 답변을 테스트 ID별로 맞추고 BERTScore Precision·Recall·F1을 계산할 수 있습니다.
- 점수 구간별 상태, 케이스별 QA 의견과 전체 권고가 CSV와 Markdown 보고서에 일관되게 생성되면 완료입니다.

## 후속 실습과의 관계

`38_AB테스트_배포판정`에서 기준 모델 비교를 Golden Set, 회귀 허용치, 사실·안전·핵심 기능 조건이 있는 배포 판정으로 확장합니다.

## 이어서 학습하면 좋은 내용

- 낮은 BERTScore 사례를 사람이 검토해 실제 회귀와 허용 가능한 표현 차이를 구분합니다.
- 숫자·날짜·안전성처럼 의미 유사도만으로 판단하기 어려운 별도 검사 항목을 추가합니다.
