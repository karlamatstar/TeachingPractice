실습 시 실행 순서
----------------------------------------------
1단계
streamlit run app/app.py
---
웹 대시보드 실행


2단계 (별도 터미널)
python src/main.py
---
평가 엔진 실행

----------------------------------------------
현재 프로젝트 전체 구조
----------------------------------------------
app/
 └─ app.py
      ↓
      사용자 입력(UI)

src/
 ├─ main.py
 │    ↓
 │    평가 파이프라인
 │
 ├─ runner/
 │    └─ llm_judge.py
 │
 ├─ engine/
 │    ├─ calculator.py
 │    └─ filter.py
 │
 └─ utils/
      └─ config_loader.py

config/
 └─ policy_config.json

data/
 └─ test_cases.json

쉽게 말하면,

app.py = 자동차의 계기판(화면)
src/main.py = 자동차의 엔진(평가 로직)
calculator.py = 점수 계산기
filter.py = 합격/불합격 심사관
policy_config.json = 평가 규정집
test_cases.json = 테스트 데이터

역할을 담당하는 구조입니다.


app.py
- Streamlit 웹 대시보드
- 사람이 점수를 직접 조정
- 결과를 화면에서 확인

main.py
- 터미널 실행용 자동 평가
- test_cases.json을 읽어 평가
- Fail이면 sys.exit(1)로 배포 중단 가능

즉, app.py는 교육용·시각화용, main.py는 자동화·CI/CD용입니다.
