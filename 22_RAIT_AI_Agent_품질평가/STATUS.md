# 실습 상태

- 상태: **평가 구조 학습 완료**
- 강의 제목: AI Agent 품질을 측정하는 프레임워크
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-06-09~06-10 · 9~10일차
- 학습 수준: 중급

## 실습 요약

정책·테스트 데이터·Judge·점수 계산·배포 판정을 연결하는 RAIT 품질평가 실습입니다.

## 이 단계의 완료 기준

- 정책과 테스트 케이스를 불러와 Agent 응답을 Judge로 평가하고 필터·점수 계산기로 전달하는 전체 파이프라인을 추적할 수 있습니다.
- 품질 점수와 정책 임계값을 근거로 통과 또는 배포 판정이 내려지는 방식을 설명하면 완료입니다.

## 후속 실습과의 관계

`23_RAIT_Pytest_E2E_자동화`는 RAIT의 Agent·Judge 판정을 API 및 UI 자동 테스트와 결함 증거로 확장하는 직접 후속 실습입니다.

## 이어서 학습하면 좋은 내용

- 같은 응답에 정책과 임계값을 다르게 적용해 판정 변화가 타당한지 비교합니다.
- 실제 Judge 실패와 Mock 평가 결과를 구분해 보고하도록 실행 모드를 명확히 표시합니다.
