# 실습 상태

- 상태: **기초 단계 학습 완료**
- 강의 제목: LangGraph RAG 확장 실습
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 학습 흐름: LangGraph 기반 RAG
- 학습 수준: 중급

## 실습 요약

LangGraph 흐름 안에 검색과 응답 생성을 배치하는 실습입니다.

## 이 단계의 완료 기준

- 노트북에서 질문, 검색 결과와 생성 답변이 어떤 상태 필드로 이동하는지 확인할 수 있습니다.
- 검색 노드와 생성 노드의 실행 순서 및 검색 결과가 없을 때의 응답 경로를 설명하면 완료입니다.

## 후속 실습과의 관계

LangGraph 안에 RAG를 배치하는 최소 사례로 마무리됩니다. `30_RAG_챗봇_단계별구축`은 같은 개념을 품질평가 프로젝트 수준으로 확장해 볼 수 있는 후속 실습입니다.

## 이어서 학습하면 좋은 내용

- 관련 문서가 없는 질문을 별도 분기로 처리해 무근거 답변을 막습니다.
- 검색 문서와 최종 답변을 상태 로그에 함께 남겨 추적 가능성을 높입니다.

## 폴더 구성

- `README.md`: 실습 개요와 실행 안내
- `src`: 코드와 단계별 실습 자료
- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
