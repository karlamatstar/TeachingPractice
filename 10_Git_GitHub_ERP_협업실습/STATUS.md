# 실습 상태

- 상태: **협업 자료 정리 완료**
- 강의 제목: Git/GitHub를 활용한 소프트웨어 개발 및 협업
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-06-04 · 6일차
- 학습 수준: 중급

## 실습 요약

Spring·React ERP 예제를 기준으로 저장소 구조와 프론트·백엔드 협업 흐름을 확인하는 실습입니다.

## 이 단계의 완료 기준

- Spring 백엔드의 컨트롤러·서비스·저장소 구조와 React 프론트의 역할을 ERP 업무 흐름에 맞춰 설명할 수 있습니다.
- 팀 저장소에서 브랜치, 커밋, 병합 충돌과 프론트·백엔드 인터페이스를 어떻게 나누는지 파악하면 이 자료 정리는 완료입니다.

## 후속 실습과의 관계

ERP 예제로 Git/GitHub 협업 구조를 살펴보는 독립 자료입니다. 게임 정보 챗봇 테스트와 코드·과제 관계가 없어 연결하지 않습니다.

## 이어서 학습하면 좋은 내용

- 출결·인사 등 한 기능을 골라 API 계약과 담당자별 변경 범위를 문서화합니다.
- 충돌 재현용 브랜치를 만들어 병합·리뷰·복구 절차를 실제로 연습합니다.

## 폴더 구성

- `README.md`: 실습 개요와 실행 안내
- `src`: 코드와 단계별 실습 자료
- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
