## 로그인

### 1. 화면 개요

| 항목 | 내용 |
| --- | --- |
| 화면명 | 로그인 |
| 목적 | 사용자 인증 후 인사관리시스템에 접속 |
| 주요 기능 | 일반 로그인, 로그인 상태 유지, 비밀번호 찾기, 카카오 로그인, 회원가입 신청 |

### 2. 화면 구성

| 영역 | 내용 |
| --- | --- |
| 상단 메뉴 | 인사관리, 근태관리, 급여관리, 일용직관리 |
| 좌측 영역 | 서비스 소개 및 주요 기능 안내 |
| 우측 영역 | 이메일·비밀번호 입력 및 로그인 기능 |

### 3. 기능 요구사항

| ID | 항목 | 요구사항 |
| --- | --- | --- |
| LOGIN-001 | 이메일 | 필수 입력이며 이메일 형식으로 입력해야 한다 |
| LOGIN-002 | 비밀번호 | 필수 입력이며 기본적으로 마스킹 처리한다 |
| LOGIN-003 | 비밀번호 보기 | 눈 아이콘 클릭 시 비밀번호 표시·숨김을 전환한다 |
| LOGIN-004 | 로그인 | 정상 인증 시 메인 화면으로 이동한다 |
| LOGIN-005 | 로그인 실패 | 인증 실패 시 오류 메시지를 표시한다 |
| LOGIN-006 | 상태 유지 | 선택 시 재접속 후에도 로그인 상태를 유지한다 |
| LOGIN-007 | 비밀번호 찾기 | 비밀번호 재설정 화면으로 이동한다 |
| LOGIN-008 | 카카오 로그인 | 카카오 인증 화면으로 이동한다 |
| LOGIN-009 | 회원가입 | 회원가입 신청 화면으로 이동한다 |
| LOGIN-010 | 중복 요청 | 로그인 처리 중 버튼 중복 클릭을 방지한다 |

### 4. 예외 처리

| 상황 | 처리 |
| --- | --- |
| 이메일 미입력 | 이메일 입력 안내 메시지 표시 |
| 잘못된 이메일 형식 | 이메일 형식 오류 메시지 표시 |
| 비밀번호 미입력 | 비밀번호 입력 안내 메시지 표시 |
| 인증 실패 | 이메일 또는 비밀번호 불일치 메시지 표시 |
| 서버 오류 | 잠시 후 다시 시도하라는 메시지 표시 |
| 네트워크 오류 | 네트워크 연결 확인 메시지 표시 |

### 5. 주요 QA 확인 항목

- 정상 로그인 성공 여부
- 이메일·비밀번호 미입력 처리
- 잘못된 이메일 형식 처리
- 잘못된 계정 로그인 실패 처리
- 비밀번호 표시·숨김 기능
- 로그인 버튼 연속 클릭 시 중복 요청 여부
- 로그인 상태 유지 여부
- 비밀번호 찾기 이동 여부
- 카카오 로그인 이동 여부
- 회원가입 신청 이동 여부
- 모바일 및 작은 화면에서 UI 깨짐 여부
- Console 오류 및 Network 응답 상태 확인

### 6. 기획 확인 필요 사항

- 로그인 성공 후 이동 화면
- 로그인 상태 유지 기간
- 로그인 실패 횟수 제한
- 비밀번호 최소·최대 길이
- 회원가입 승인 방식
- 로그인 전 상단 메뉴 접근 가능 여부

## 회원가입

### 1. 화면 개요

| 항목 | 내용 |
| --- | --- |
| 화면명 | 회원가입 |
| 목적 | 사용자 계정을 생성하여 인사관리시스템을 이용 |
| 주요 기능 | 사용자 정보 입력, 부서·직급 선택, 비밀번호 설정, 약관 동의 |

### 2. 입력 항목

| 항목 | 조건 |
| --- | --- |
| 성 | 필수 입력 |
| 이름 | 필수 입력 |
| 사번 | 필수 입력, 중복 불가 |
| 부서 | 목록에서 선택 |
| 직급 | 목록에서 선택 |
| 회사 이메일 | 필수 입력, 이메일 형식 |
| 비밀번호 | 영문·숫자·특수문자를 포함한 8자 이상 |
| 비밀번호 확인 | 비밀번호와 동일하게 입력 |
| 이용약관 동의 | 필수 동의 |

### 3. 기능 요구사항

| ID | 항목 | 요구사항 |
| --- | --- | --- |
| SIGNUP-001 | 이름 | 성과 이름을 필수로 입력해야 한다 |
| SIGNUP-002 | 사번 | 사번은 필수이며 기존 사번과 중복될 수 없다 |
| SIGNUP-003 | 부서 | 등록된 부서 목록 중 하나를 선택해야 한다 |
| SIGNUP-004 | 직급 | 등록된 직급 목록 중 하나를 선택해야 한다 |
| SIGNUP-005 | 이메일 | 회사 이메일 형식으로 입력해야 한다 |
| SIGNUP-006 | 비밀번호 | 영문·숫자·특수문자를 포함하여 8자 이상 입력해야 한다 |
| SIGNUP-007 | 비밀번호 확인 | 비밀번호와 동일해야 한다 |
| SIGNUP-008 | 약관 | 이용약관 및 개인정보처리방침에 동의해야 한다 |
| SIGNUP-009 | 회원가입 | 모든 입력값이 정상일 때 회원가입을 처리한다 |
| SIGNUP-010 | 로그인 이동 | 로그인하기 클릭 시 로그인 화면으로 이동한다 |

### 4. 예외 처리

| 상황 | 처리 |
| --- | --- |
| 필수값 미입력 | 해당 항목 아래에 입력 안내 메시지 표시 |
| 사번 중복 | 이미 등록된 사번이라는 메시지 표시 |
| 이메일 형식 오류 | 올바른 이메일 형식 안내 |
| 이메일 중복 | 이미 등록된 이메일이라는 메시지 표시 |
| 비밀번호 조건 불충족 | 비밀번호 작성 조건 안내 |
| 비밀번호 불일치 | 비밀번호가 일치하지 않는다는 메시지 표시 |
| 약관 미동의 | 약관 동의 필요 메시지 표시 |
| 서버 오류 | 잠시 후 다시 시도하라는 메시지 표시 |

### 5. 주요 QA 확인 항목

- 모든 필수값 정상 입력 후 회원가입 성공
- 각 필수값 미입력 처리
- 사번 및 이메일 중복 확인
- 부서·직급 목록 선택
- 잘못된 이메일 형식 입력
- 비밀번호 조건 및 경계값 확인
- 비밀번호와 비밀번호 확인 불일치
- 비밀번호 표시·숨김 기능
- 약관 미동의 상태에서 가입 시도
- 회원가입 버튼 연속 클릭 시 중복 가입 여부
- 로그인하기 클릭 시 로그인 화면 이동
- 모바일 및 작은 화면에서 UI 깨짐 여부

### 6. 기획 확인 필요 사항

- 회원가입 즉시 사용 가능한지 관리자 승인이 필요한지
- 사번 입력 형식과 최대 길이
- 회사 이메일 도메인 제한 여부
- 부서와 직급 목록 관리 방식
- 약관 내용 보기 표시 방식
- 회원가입 성공 후 이동 화면

## 인사정보등록

### 1. 화면 개요

| 항목 | 내용 |
| --- | --- |
| 화면명 | 인사정보등록 |
| 목적 | 직원 정보를 조회하고 신규 등록 또는 수정 |
| 주요 기능 | 직원 조회, 검색 조건 초기화, 신규 등록, 수정, PDF 다운로드 |

| ID | 항목 | 요구사항 |
| --- | --- | --- |

| EMP-002 | 사원번호 검색 | 사원번호를 입력하여 직원을 조회한다 |
| EMP-003 | 부서 검색 | 선택한 부서에 해당하는 직원만 조회한다 |

| EMP-006 | 초기화 | 검색 조건을 기본값으로 초기화한다 |
| EMP-007 | 신규등록 | 신규등록 버튼 클릭 시 등록 모달을 표시한다 |
| EMP-008 | 수정 | 수정 버튼 클릭 시 선택한 직원 정보 수정 화면을 표시한다 |
| EMP-009 | 페이지 이동 | 페이지 번호 또는 이전·다음 버튼으로 목록을 이동한다 |
| EMP-010 | PDF 다운로드 | 현재 직원 목록을 PDF로 다운로드한다 |

### 3. 신규등록 입력 항목

| 항목 | 조건 |
| --- | --- |
| 사원번호 | 필수, 자동 생성 또는 중복 불가 |
| 성명 | 필수 |
| 부서 | 필수 선택 |
| 직급 | 필수 선택 |
| 입사일 | 필수, 날짜 형식 |
| 재직상태 | 필수 선택 |
| 휴대폰 | 필수, 전화번호 형식 |
| 이메일 | 이메일 형식 |
| 우편번호 | 주소 검색으로 입력 |
| 도로명주소 | 주소 검색 결과 자동 입력 |
| 상세주소 | 사용자 직접 입력 |
| 비상연락처 성명 | 선택 입력 |
| 관계 | 목록에서 선택 |
| 비상연락처 | 전화번호 형식 |

- 필수값 미입력 처리
- 사원번호 중복 등록

- PDF 다운로드 정상 동작
- 긴 이름·이메일 입력 시 UI 깨짐 여부

### 7. 기획 확인 필요 사항

- 사원번호 자동 생성 여부

- 퇴직 직원 수정 가능 여부
- 이메일과 휴대폰 중복 허용 여부
- 모달 외부 영역 클릭 시 닫히는지
- 수정 화면이 신규등록 모달과 동일한 형식인지

## 인사발령등록

### 1. 화면 개요

| 항목 | 내용 |
| --- | --- |
| 화면명 | 인사발령등록 |
| 목적 | 직원의 부서·직급·직책 변경 이력을 등록하고 관리 |
| 주요 기능 | 직원 검색, 발령 등록, 발령 이력 조회·수정·삭제, 인사기록카드 확인 |

### 2. 검색 기능

| ID | 항목 | 요구사항 |
| --- | --- | --- |
| APPOINT-001 | 직원 검색 | 사원번호 또는 성명으로 직원을 검색한다 |
| APPOINT-002 | 발령유형 검색 | 전체·승진·전보·겸직·기타 조건으로 조회한다 |
| APPOINT-003 | 발령일 검색 | 시작일과 종료일 범위로 조회한다 |
| APPOINT-004 | 초기화 | 입력한 검색 조건을 기본값으로 초기화한다 |

### 3. 발령 등록 항목

| 항목 | 조건 |
| --- | --- |
| 발령유형 | 필수 선택 |
| 발령일 | 필수 입력 |
| 발령번호 | 자동 생성 |
| 발령사유 | 선택 입력 |
| 발령 전 부서·직급·직책 | 현재 직원 정보 자동 표시 |
| 발령 후 부서·직급·직책 | 변경할 정보 선택 |
| 비고 | 선택 입력 |

### 4. 기능 요구사항

| ID | 항목 | 요구사항 |
| --- | --- | --- |

## 월근태현황

### 1. 화면 개요

| 항목 | 내용 |
| --- | --- |
| 화면명 | 월근태현황 |
| 목적 | 부서별·직원별 월간 근태 현황 조회 |
| 주요 기능 | 월 선택, 부서 조회, 일자별 근태 확인, PDF 다운로드, 인쇄 |

### 2. 조회 기능

| ID | 항목 | 요구사항 |
| --- | --- | --- |
| MONTH-001 | 월 선택 | 이전·다음 버튼으로 조회 월을 변경한다 |
| MONTH-002 | 부서 조회 | 선택한 부서의 직원만 조회한다 |
| MONTH-003 | 조회 | 선택한 월과 부서 조건으로 근태 현황을 표시한다 |
| MONTH-004 | 근태 구분 | 출근·지각·연차·반차·출장·결근·휴일을 구분하여 표시한다 |
| MONTH-005 | 합계 | 직원별 출근·지각·연차·결근 횟수를 표시한다 |
| MONTH-006 | 근무일수 | 선택한 월의 총 근무일수를 표시한다 |
| MONTH-007 | 대상 인원 | 조회된 직원 수를 표시한다 |
| MONTH-008 | PDF 다운로드 | 현재 조회 결과를 PDF로 다운로드한다 |
| MONTH-009 | 인쇄 | 현재 조회 결과를 인쇄한다 |

### 3. 표시 항목

| 항목 | 내용 |
| --- | --- |
| 성명 | 직원 이름 |
| 부서 | 소속 부서 |
| 일자별 근태 | 각 날짜의 근태 상태 |
| 출근 | 정상 출근 일수 |
| 지각 | 지각 일수 |
| 연차 | 연차 사용 일수 |
| 결근 | 결근 일수 |

### 4. 예외 처리

| 상황 | 처리 |
| --- | --- |
| 조회 결과 없음 | 조회된 근태 정보가 없다는 메시지 표시 |
| 조회 실패 | 근태 현황을 불러올 수 없다는 메시지 표시 |
| PDF 생성 실패 | 다운로드 실패 메시지 표시 |
| 인쇄 실패 | 인쇄할 수 없다는 메시지 표시 |

### 5. 주요 QA 확인 항목

- 이전·다음 월 이동
- 부서별 조회 결과
- 월별 일수 및 요일 표시
- 주말·휴일 표시
- 근태 상태별 색상과 범례 일치
- 일일근태 등록 데이터와 월 현황 일치
- 직원별 근태 합계 계산
- 총 근무일수 및 대상 인원 표시
- 데이터가 많은 경우 가로 영역 표시
- PDF 다운로드 결과
- 인쇄 화면과 조회 화면 일치 여부

### 6. 기획 확인 필요 사항

- 반차를 연차 합계에 0.5일로 계산하는지
- 출장·교육·공가를 출근 일수에 포함하는지
- 법정공휴일과 회사 휴일의 표시 기준
- 퇴직자와 중도 입사자의 조회 기준
- 미래 날짜의 근태 표시 방식
- PDF와 인쇄 대상이 전체 부서인지 현재 조회 결과인지

## 급여기본정보관리

### 1. 화면 개요

| 항목 | 내용 |
| --- | --- |
| 화면명 | 급여기본정보관리 |
| 목적 | 직원별 기본급, 수당, 지급계좌 정보를 등록·수정 |
| 주요 기능 | 급여정보 조회, 개별 수정, 일괄 수정, 신규 등록, 이력 확인, PDF 다운로드 |

### 2. 조회 기능

| ID | 항목 | 요구사항 |
| --- | --- | --- |
| SALARY-001 | 부서 조회 | 선택한 부서의 직원만 조회한다 |
| SALARY-002 | 직급 조회 | 선택한 직급의 직원만 조회한다 |
| SALARY-003 | 적용기준일 | 선택한 기준일의 급여정보를 조회한다 |
| SALARY-004 | 사원 검색 | 사원명으로 직원을 검색한다 |
| SALARY-005 | 초기화 | 검색 조건을 기본값으로 초기화한다 |

### 3. 표시 및 입력 항목

| 항목 | 내용 |
| --- | --- |
| 기본급 | 직원별 기본 급여 |
| 식대 | 식대 수당 |
| 교통비 | 교통비 수당 |
| 직책수당 | 직책에 따른 수당 |
| 수당합계 | 등록된 수당의 합계 |
| 은행 | 급여 지급 은행 |
| 계좌번호 | 마스킹하여 표시 |
| 적용시작일 | 급여정보 적용 시작일 |

### 4. 기능 요구사항

| ID | 항목 | 요구사항 |
| --- | --- | --- |
| SALARY-006 | 요약정보 | 평균·최고 기본급, 월 총 인건비, 월 총 수당, 등록 인원을 표시한다 |
| SALARY-007 | 개별 수정 | 수정 버튼 클릭 시 해당 직원 급여정보를 수정할 수 있다 |
| SALARY-008 | 저장 | 수정값이 정상일 때 저장하고 목록에 반영한다 |
| SALARY-009 | 취소 | 수정 중인 값을 저장 전 상태로 되돌린다 |
| SALARY-010 | 이력 | 직원별 급여정보 변경 이력을 조회한다 |
| SALARY-011 | 일괄 수정 | 선택한 여러 직원의 급여정보를 한 번에 수정한다 |
| SALARY-012 | 신규 등록 | 급여정보가 없는 직원의 정보를 등록한다 |
| SALARY-013 | 합계 계산 | 기본급과 수당 항목의 합계를 자동 계산한다 |
| SALARY-014 | PDF 다운로드 | 현재 조회 결과를 PDF로 다운로드한다 |

### 5. 예외 처리

| 상황 | 처리 |
| --- | --- |
| 기본급 미입력 | 기본급 입력 안내 |
| 음수 금액 입력 | 0원 이상의 금액 입력 안내 |
| 숫자 형식 오류 | 숫자만 입력하도록 처리 |
| 적용일 미입력 | 적용일 선택 안내 |
| 계좌정보 미입력 | 지급계좌 입력 안내 |
| 중복 적용일 등록 | 동일 적용일의 정보가 있다는 메시지 표시 |
| 저장 실패 | 저장 실패 메시지 표시 |

### 6. 주요 QA 확인 항목

- 부서·직급·기준일별 조회
- 사원 검색 및 초기화
- 기본급·수당 개별 수정
- 수당합계와 전체 합계 자동 계산
- 요약정보와 목록 합계 일치 여부
- 저장·취소 동작
- 여러 직원 선택 후 일괄 수정
- 신규 급여정보 등록
- 계좌번호 마스킹 여부
- 급여 변경 이력 조회
- 페이지 이동 및 총 인원 표시
- PDF 다운로드 결과

### 7. 기획 확인 필요 사항

- 월 총 인건비에 수당이 포함되는지
- 기본급과 수당의 최대 입력 금액
- 동일 직원의 급여 적용기간 중복 허용 여부
- 일괄 수정 가능한 항목 범위
- 과거 급여정보 수정 가능 여부
- 계좌번호 전체 조회 권한
- 수정 시 승인 절차가 필요한지

| --- | --- |
| 화면명 | 급여지급 |
| 목적 | 월별 직원 급여를 조회하고 최종 확정 |
| 주요 기능 | 급여 조회, 지급·공제 내역 확인, 급여 확정, 명세서 출력, PDF 다운로드 |

### 2. 조회 기능

| ID | 항목 | 요구사항 |

| 급여 확정 실패 | 확정 실패 메시지 표시 |
| 명세서 출력 실패 | 출력 실패 메시지 표시 |

### 6. 주요 QA 확인 항목

- 월·부서·사원별 조회
- 지급소계 계산
- 공제소계 계산
- 실지급액 계산
- 직원별 금액과 전체 합계 일치
- 요약 카드와 목록 합계 일치
- 미확정·확정 인원 표시
- 여러 직원 선택 동작
- 급여 확정 후 상태 변경
- 확정 버튼 연속 클릭 시 중복 처리 여부
- 급여명세서 출력
- PDF 다운로드
- 페이지 이동 및 총 인원 표시

### 7. 기획 확인 필요 사항

- 급여 확정 후 수정 가능 여부
- 일부 직원만 선택하여 확정할 수 있는지
- 급여 확정 전 승인 절차가 필요한지
- 4대 보험과 세금 계산 기준
- 급여명세서 발송 기능 포함 여부
- 퇴직자와 중도 입사자의 급여 계산 기준
- 전월 대비 증감액 계산 기준
