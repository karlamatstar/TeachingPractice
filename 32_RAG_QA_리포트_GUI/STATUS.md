# 실습 상태

- 상태: **GUI 리포트 실습 완료**
- 강의 제목: AI Agent 품질 진단 피드백
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-06-25 · 21일차
- 학습 수준: 중급

## 실습 요약

RAG 데이터 재구축, Judge 실행, 결과 열람을 GUI에서 다루는 실습입니다.

## 이 단계의 완료 기준

- 런처에서 RAG 채팅, 벡터 DB 재구축과 Judge 실행 화면을 각각 열 수 있는 구조를 확인할 수 있습니다.
- 채팅 로그, 테스트 결과, JSON 평가 결과와 Markdown 최종 보고서가 `_OUTPUT`의 구분된 폴더에 생성·열람되면 완료입니다.

## 후속 실습과의 관계

RAG 운영과 QA 결과 열람을 GUI로 묶은 완결형 실습입니다. BERTScore 지표 실습은 별도의 정량 평가 예제이므로 연결하지 않습니다.

## 이어서 학습하면 좋은 내용

- 데이터 재구축 중 입력 잠금·진행률·실패 메시지를 GUI에서 명확히 표시합니다.
- 보고서 화면에서 테스트 ID와 원문 질문·답변·출처를 바로 추적할 수 있게 연결합니다.

## 폴더 구성

- `README.md`: 실습 개요와 실행 안내
- `src`: 코드와 단계별 실습 자료
- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
