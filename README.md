# 실습 및 프로젝트 정리

AI·QA 강의 진행에 맞춰 수행한 실습과 프로젝트를 학습 순서대로 정리했습니다. OpenAI API와 프롬프트 기초에서 시작해 Agent·RAG·자동 품질평가·운영 모니터링·AWS QA·데이터 분석으로 확장되는 과정을 담았습니다.

## GitHub 공개 범위

- 포함: 이 `README.md`와 `01_`부터 `45_`까지의 모든 실습 폴더
- 제외: 저장소 루트의 `_DOCS`, 실제 `.env`, 인증서·비밀정보, 가상환경, 설치 모듈, 캐시, IDE 설정 및 재생성 가능한 벡터 저장소
- 환경변수 예시는 `.env.example`로 제공하며 실제 키는 기록하지 않습니다.
- 각 실습의 소스 코드, 내부 문서, 최종 결과물과 의존성 설치 목록은 보존합니다.

## 공통 구조

- `src`: 코드와 단계별 실습
- `_DOCS`: 설명서·계획서·의존성 복구 안내
- `_OUTPUT`: 로그·리포트·실행 결과
- `.env`: 필요할 때만 프로젝트 최상위에 배치하고 Git에서 제외
- 설치 목록: `requirements.txt`, `package.json`, `pyproject.toml` 등으로 보존

각 폴더의 `STATUS.md`는 실제 코드·문서·산출물을 기준으로 무엇을 확인하면 완료인지 설명합니다. 후속 실습은 직접적인 확장 관계가 확인될 때만 연결하며, 독립 실습은 해당 폴더에서 마무리됨을 표시합니다.
