## 자료 확인 방법

- 각 폴더의 `README.md`에는 실습 개요, 주요 진입점, 필요한 실행 환경과 의존성 설치 방법이 정리되어 있습니다.
- `STATUS.md`에는 코드·문서·산출물에서 확인할 내용과 해당 실습이 다루는 범위가 기록되어 있습니다.
- `src`에는 코드와 단계별 실습 자료, `_DOCS`에는 설명서와 복구 안내, `_OUTPUT`에는 보존할 가치가 있는 로그·리포트·결과물이 들어 있습니다.
- Python 가상환경, `node_modules`, Docker 이미지와 외부 서비스는 저장소에 포함하지 않습니다. `requirements.txt`, `package.json`, `pyproject.toml` 등의 설치 목록을 환경 복구 기준으로 사용합니다.
- 실습별로 필요한 Python·Node.js·Java·Docker·브라우저 도구·로컬 LLM·클라우드 계정이 다르므로, 이 저장소 전체가 하나의 환경에서 일괄 실행된다고 전제하지 않습니다.
- 실제 API 키와 인증정보는 기록하지 않으며, 필요한 항목만 `.env.example` 또는 개별 안내 문서에서 확인할 수 있습니다.

## 저장소 구성 원칙

- 실행 코드와 단계별 실습은 `src`, 문서는 `_DOCS`, 보존할 결과물은 `_OUTPUT`을 기본 위치로 사용합니다.
