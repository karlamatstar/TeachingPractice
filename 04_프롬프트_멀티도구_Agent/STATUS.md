# 실습 상태

- 상태: **단계 실습 완료**
- 강의 제목: 프롬프트의 비밀 / 효과적인 프롬프트 개발
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-05-29–06-01 · 3–4일차
- 학습 수준: 초급

## 실습 요약

날씨·일정·계산·검색·메일 도구를 선택해 호출하는 LangChain Agent 실습입니다.

## 이 단계의 완료 기준

- 날씨·일정·계산·검색·메일 요청에 맞는 도구 스키마와 실행 함수가 선택되는 과정을 확인할 수 있습니다.
- 터미널 또는 GUI에서 도구 결과가 최종 답변으로 합쳐지고, 잘못된 입력이 안전하게 처리되는지 확인하면 완료입니다.

## 후속 실습과의 관계

여러 도구를 선택하는 Agent 구현 자체로 마무리됩니다. 문서 요약 실습은 입력 자료와 처리 목적이 달라 연결하지 않습니다.

## 이어서 학습하면 좋은 내용

- 도구를 호출하지 않아야 하는 일반 대화와 여러 도구가 필요한 복합 요청을 테스트합니다.
- 외부 검색 실패와 잘못된 계산식의 오류 메시지를 사용자 관점에서 다듬습니다.
