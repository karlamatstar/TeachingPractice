`quality/test_cases.json`은 실행 비용·시간 절약을 위해 2026-07-06부터 **5건 축소판**으로 운영합니다.
이 문서는 원래의 전체 30건(Happy 16 / Edge 11 / Negative 3)을 기록해둔 아카이브입니다.
케이스를 다시 늘리고 싶으면 아래 표에서 골라 `quality/test_cases.json`에 같은 형식으로 추가하면 됩니다.
