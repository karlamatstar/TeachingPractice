# 단계 자료 설명

`src/stage_01_portfolio`는 운영 플랫폼을 만들기 전에 폴더와 역할을 먼저 설계한 기초 골격입니다. 일부 코드·문서 파일이 비어 있는 것은 캐시나 오류 파일이 아니라, API·Judge·품질 파이프라인·대시보드·모니터링·테스트의 위치를 먼저 잡아 본 학습 기록입니다.

실제 구현과 산출물은 이 프로젝트의 최상위 `app`, `quality`, `performance`, `monitoring`, `dashboard`, `tests`, `_OUTPUT`에서 이어집니다. 따라서 기초 골격에서는 구성 요소의 역할과 배치를 확인하고, 구현 동작은 확장된 운영 플랫폼에서 확인하면 됩니다.
