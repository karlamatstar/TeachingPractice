# OpenAI 모델 업그레이드 계획서 (gpt-4.1-mini ➡️ gpt-5.4-mini)

현재 프로젝트의 챗봇 답변 및 채점 모델로 사용 중인 `gpt-4.1-mini`를 성능과 응답 속도가 대폭 개선된 최신 경량화 모델인 `gpt-5.4-mini`로 교체하기 위한 계획서입니다.

## 1. 교체 배경 및 기대 효과
- **응답 속도(Latency) 개선**: 첫 글자 출력 시간(TTFT) 및 초당 토큰 생성 속도 증가로 사용자 체감 대기 시간 단축.
- **백그라운드 태스크 부하 감소**: 사용자 질문 발생 시 백그라운드에서 실행되는 2건의 AI 채점(API 기반, 규칙 기반)이 훨씬 빠르게 종료되어 서버 리소스(스레드) 반환 속도 증가.
- **동시 접속자(Throughput) 향상**: 서버 부하가 줄어듦에 따라 k6 부하 테스트 시 기존 모델 대비 더 많은 동시 접속자를 안정적으로 처리할 수 있을 것으로 기대됨.
- **비용 유지**: mini 계열 모델 유지로 기존과 유사한 수준의 저렴한 API 호출 비용으로 고성능 확보.

## 2. 변경 대상 및 방법
실제 애플리케이션 코드를 수정할 필요 없이, 환경 변수(`.env`)만 변경하여 즉시 교체 가능하도록 구현되어 있습니다.

**[기존 `.env` 설정]**
```env
OPENAI_MODEL=gpt-4.1-mini
```

**[변경 `.env` 설정]**
```env
OPENAI_MODEL=gpt-5.4-mini
```
*(참고: `app/config.py` 파일 내에 `OPENAI_MODEL` 환경 변수를 불러오도록 이미 세팅되어 있으므로 코드 수정은 불필요합니다.)*

## 3. 검증 계획
1. **단위 테스트**: 모델 변경 후 단일 사용자 질문을 전송하여 답변이 정상적으로 오는지, 채점 결과(PASS/FAIL)가 지라에 잘 등록되는지 확인.
2. **성능 검증 (k6 비교 테스트)**:
   - 기존(`4.1-mini`) 환경에서 동시 접속자 50명 수준으로 1분간 테스트 기록 보관.
   - 신규(`5.4-mini`) 환경에서 동일 조건으로 테스트 실행 후 Grafana 대시보드를 통해 응답 지연(Latency) 개선율 및 타임아웃 감소 여부 비교 분석.
3. **최종 리포트 반영**: 향후 `reports/final_defect_report.docx` 생성 시 "AI 에이전트 종합 의견" 작성에도 `gpt-5.4-mini` 모델이 활용되어, 빠르고 일관된 의견을 도출하도록 함.
