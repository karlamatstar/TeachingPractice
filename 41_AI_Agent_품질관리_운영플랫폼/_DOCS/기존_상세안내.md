# AI Agent 품질관리 운영 플랫폼

FastAPI, pytest, LLM Judge, k6, Prometheus, Grafana, Streamlit과 Docker를 연결한 수업 프로젝트입니다.

## 공통 위치

- `_DOCS`: 실행·설계·품질관리 문서
- `_OUTPUT/quality`: 평가 리포트, 로그, 결함 증적
- `_OUTPUT/performance`: k6 실행 결과
- `app`, `quality`, `dashboard`, `performance`: 기능별 코드

전체 실행 절차는 `_DOCS/README.md`, 현재 검증 범위는 `STATUS.md`를 확인합니다.
