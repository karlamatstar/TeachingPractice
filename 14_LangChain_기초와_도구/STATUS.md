# 실습 상태

- 상태: **기초 단계 학습 완료**
- 강의 제목: LangChain 구성 요소 확장 실습
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 학습 흐름: LangChain 구성 요소와 도구 활용
- 학습 수준: 초급

## 실습 요약

메시지 기록, LCEL, Pydantic 도구, 스트리밍과 Streamlit 연동을 다루는 실습입니다.

## 이 단계의 완료 기준

- LangChain 메시지 기록과 LCEL 체인이 입력을 모델 출력으로 전달하는 과정을 설명할 수 있습니다.
- Pydantic 기반 도구, 스트리밍과 Streamlit 세션 기록을 각각 실행하거나 코드에서 동작 경로를 확인하면 완료입니다.

## 후속 실습과의 관계

`15_LangChain_RAG_기초`는 여기서 익힌 체인 구성에 문서 검색기를 결합하는 직접 후속 실습입니다.

## 이어서 학습하면 좋은 내용

- 동일 기능을 일반 함수 호출과 LangChain 도구 방식으로 구현해 복잡도를 비교합니다.
- 세션 ID가 바뀔 때 대화 기록이 분리되는지 테스트합니다.

## 폴더 구성

- `src`: 코드와 단계별 실습 자료
- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
