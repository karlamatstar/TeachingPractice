# 실습 상태

- 상태: **통합 프로젝트 구조 정리 완료**
- 강의 제목: VOC Improve 및 QA 프로젝트
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-07-13–07-16 · 33–36일차
- 학습 수준: 고급

## 실습 요약

VOC 분석·개선 Agent와 독립 LLM Judge, 교차검증, GUI·보고서를 통합한 프로젝트입니다.

## 이 단계의 완료 기준

- Retriever·Summarizer·Interpreter·Critic·Improver·Evaluator 역할이 VOC 데이터를 검색하고 개선안과 평가를 만드는 과정을 추적할 수 있습니다.
- gRPC 실행, GUI 런처, pytest와 독립 LLM Judge·교차검증 결과가 CSV·Markdown·DOCX 보고서로 일관되게 남으면 완료입니다.

## 후속 실습과의 관계

VOC 분석·개선·검증을 하나로 통합한 독립 최종 프로젝트입니다. 뒤의 응답 품질평가 기초 실습은 더 작은 교육용 예제이며 이 프로젝트의 다음 구현 단계가 아닙니다.

## 이어서 학습하면 좋은 내용

- 생성 모델과 Judge 모델 조합별 결과를 같은 VOC 세트로 교차 비교합니다.
- Agent 실패·Judge 미사용·외부 서비스 중단을 N/A와 결함으로 구분해 보고합니다.
