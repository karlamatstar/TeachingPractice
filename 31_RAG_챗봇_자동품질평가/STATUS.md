# 실습 상태

- 상태: **자동평가 구조 학습 완료**
- 강의 제목: RAG 기반 챗봇 Agent 자동 품질 평가
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-06-24 · 20일차
- 학습 수준: 중급

## 실습 요약

검색·답변·Judge·교정·보고서를 하나의 RAG 품질평가 흐름으로 연결한 실습입니다.

## 이 단계의 완료 기준

- 교육과정 문서를 벡터 DB로 만들고 질문에 대한 답변과 검색 출처를 반환하는 RAG 서비스를 확인할 수 있습니다.
- 테스트 세트 실행, Judge 평가, 교정 답변과 요약 지표가 JSON·Markdown 보고서에 함께 기록되면 완료입니다.

## 후속 실습과의 관계

`32_RAG_QA_리포트_GUI`는 이 RAG·Judge·보고 흐름을 데이터 재구축과 결과 열람이 가능한 데스크톱 GUI로 확장합니다.

## 이어서 학습하면 좋은 내용

- 검색 출처가 기대 문서와 일치하는지를 Judge 점수와 별도로 측정합니다.
- 교정 전후 답변을 같은 보고서 행에 배치해 개선과 새 오류를 함께 검토합니다.

## 폴더 구성

- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
