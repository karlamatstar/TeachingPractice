# 실습 상태

- 상태: **지표 학습 완료**
- 강의 제목: BERTScore와 Classifier
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-06-26 \~ 2026-06-29 · 22\~23일차
- 학습 수준: 초급

## 실습 요약

문장 의미 유사도와 분류 품질 지표를 계산하고 결과를 해석하는 실습입니다.

## 이 단계의 완료 기준

- 테스트 케이스와 두 모델 답변을 `case_id`로 대응시켜 기준 답변과 BERTScore F1을 계산할 수 있습니다.
- 케이스별 Model A·B 점수와 승자가 `_OUTPUT/bertscore_result.csv`에 저장되고 점수의 의미와 한계를 설명하면 완료입니다.

## 후속 실습과의 관계

`36_LLM_응답_품질비교`는 이 BERTScore 계산을 상태 판정과 종합 QA 의견이 포함된 기준 모델 비교 보고서로 확장합니다.

## 이어서 학습하면 좋은 내용

- 표현은 다르지만 의미가 같은 답변과 사실이 틀린 유사 문장을 넣어 지표 한계를 확인합니다.
- BERTScore 결과에 사람 검토 열을 추가해 정량 점수와 실제 품질 판단을 비교합니다.
