# 실습 상태

- 상태: **기초 단계 학습 완료**
- 강의 제목: 프롬프트의 비밀 / 효과적인 프롬프트 개발
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-05-29 \~ 2026-06-01 · 3\~4일차
- 학습 수준: 입문

## 실습 요약

제로샷·원샷·퓨샷, 단일·멀티턴 대화와 간단한 Streamlit 화면을 비교하는 실습입니다.

## 이 단계의 완료 기준

- 같은 질문을 프롬프트 없음·원샷·퓨샷 방식으로 실행하고 결과 차이를 비교할 수 있습니다.
- 단일 턴과 멀티턴 코드에서 대화 기록이 답변에 미치는 영향을 확인하고, Streamlit 화면의 세션 기록 흐름을 이해하면 완료입니다.

## 후속 실습과의 관계

프롬프트 방식과 대화 맥락을 비교하는 범위에서 독립적으로 마무리되는 실습입니다. 번호상 다음인 뉴스 멀티에이전트와 직접 공유하는 코드나 산출물은 없습니다.

## 이어서 학습하면 좋은 내용

- 동일 질문 세트를 각 프롬프트 방식에 적용해 정확성·일관성·길이를 비교합니다.
- 멀티턴에서 이전 지시가 충돌하는 사례를 추가해 맥락 유지 한계를 확인합니다.
