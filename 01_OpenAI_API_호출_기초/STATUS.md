# 실습 상태

- 상태: **기초 단계 학습 완료**
- 강의 제목: 생성형 AI 기초
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-05-28 · 2일차
- 학습 수준: 입문

## 실습 요약

환경변수 로드, 단일 응답과 스트리밍 응답으로 OpenAI API 호출 흐름을 익히는 실습입니다.

## 이 단계의 완료 기준

- `.env`에서 API 키를 불러와 OpenAI 클라이언트를 만드는 흐름을 설명할 수 있습니다.
- 단일 응답과 스트리밍 응답 코드를 구분하고, 실행 결과가 한 번에 반환되는 방식과 조각 단위로 출력되는 방식의 차이를 확인하면 완료입니다.

## 후속 실습과의 관계

`02_프롬프트_설계와_대화_기초`는 여기서 익힌 API 호출에 여러 프롬프트 패턴과 대화 기록을 적용하는 직접적인 후속 실습입니다.

## 이어서 학습하면 좋은 내용

- 하드코딩된 키가 있는 예제는 `.env` 방식으로 바꾸고 노출된 키는 폐기합니다.
- Chat Completions 예제와 Responses API 예제의 입력·출력 구조를 표로 비교합니다.
