# 실습 상태

- 상태: **기초 단계 학습 완료**
- 강의 제목: 검색 도구 Agent 확장 실습
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 학습 흐름: 검색·요약 Agent 활용
- 학습 수준: 초급

## 실습 요약

DuckDuckGo·Tavily 웹 검색과 YouTube 요약을 Agent 화면에 연결하는 실습입니다.

## 이 단계의 완료 기준

- DuckDuckGo와 Tavily 검색에서 질의와 검색 기간이 결과에 어떻게 반영되는지 확인할 수 있습니다.
- YouTube 검색·자막 요약과 웹 검색 도구가 Streamlit 대화에서 선택되어 답변으로 합쳐지는 흐름을 이해하면 완료입니다.

## 후속 실습과의 관계

웹·YouTube 검색 도구를 사용하는 Agent 예제로 독립 종료됩니다. DeepSeek RAG는 벡터 검색을 사용하므로 이 코드의 직접 후속이 아닙니다.

## 이어서 학습하면 좋은 내용

- 자막이 없거나 비공개인 영상과 검색 결과가 없는 질의를 예외 사례로 추가합니다.
- 검색 답변에 제목·URL·조회 시각이 함께 남도록 출처 형식을 통일합니다.

## 폴더 구성

- `README.md`: 실습 개요와 실행 안내
- `src`: 코드와 단계별 실습 자료
- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
