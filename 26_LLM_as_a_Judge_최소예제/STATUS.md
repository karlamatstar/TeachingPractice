# 실습 상태

- 상태: **기초 단계 학습 완료**
- 강의 제목: AI 평가자
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-06-16 · 14일차
- 학습 수준: 초급

## 실습 요약

LLM이 다른 응답을 입력받아 평가 결과를 반환하는 최소 Judge 구조를 확인하는 실습입니다.

## 이 단계의 완료 기준

- QA, 문맥 기반 QA, 추론형 QA, 기준 판정과 점수형 평가자 다섯 종류의 입력 차이를 설명할 수 있습니다.
- 같은 예측 답변에 evaluator 종류를 바꿨을 때 반환되는 판정·점수 구조를 실행 결과에서 구분하면 완료입니다.

## 후속 실습과의 관계

`27_Few_shot_Judge_평가실습`은 여기서 확인한 기본 평가자를 루브릭, 예시, 실패 재실행과 보고서가 있는 Judge 실습으로 확장합니다.

## 이어서 학습하면 좋은 내용

- 동일 사례를 여러 evaluator로 평가해 판정 불일치 원인을 기록합니다.
- 평가 모델·온도·기준 문구를 고정해 반복 실행의 일관성을 측정합니다.
