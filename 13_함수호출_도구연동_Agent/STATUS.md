# 실습 상태

- 상태: **기초 단계 학습 완료**
- 강의 제목: AI Agent 도구 호출 확장 실습
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 학습 흐름: 함수 호출과 도구 연동
- 학습 수준: 초급

## 실습 요약

시간 조회와 주식 정보 도구를 함수 호출 방식으로 연결하는 실습입니다.

## 이 단계의 완료 기준

- 시간 조회와 주식 조회·이력·추천 도구의 스키마와 함수 호출 결과를 연결할 수 있습니다.
- 터미널·Streamlit·스트리밍 변형에서 도구 호출 메시지와 최종 답변이 어떻게 달라지는지 확인하면 완료입니다.

## 후속 실습과의 관계

`14_LangChain_기초와_도구`는 같은 메시지·도구 호출 개념을 LangChain의 LCEL과 도구 추상화로 다시 구성하는 후속 단계입니다.

## 이어서 학습하면 좋은 내용

- 잘못된 종목 코드와 지원하지 않는 기간을 입력해 도구 오류 처리를 보완합니다.
- 실시간 금융 정보에는 조회 시각과 투자 조언이 아니라는 고지를 함께 표시합니다.
