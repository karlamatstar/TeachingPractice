# 실습 상태

- 상태: **기초 단계 학습 완료**
- 강의 제목: RAG 기초 확장 실습
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 학습 흐름: RAG 검색·생성 구조 기초
- 학습 수준: 초급

## 실습 요약

문서 검색기와 생성 모델을 연결하여 근거 기반 답변의 최소 구조를 만드는 실습입니다.

## 이 단계의 완료 기준

- 문서를 임베딩하고 검색기로 관련 조각을 가져오는 과정을 코드 또는 노트북에서 확인할 수 있습니다.
- 검색된 문서를 프롬프트에 넣은 답변과 검색 없이 만든 답변의 근거성 차이를 설명하면 완료입니다.

## 후속 실습과의 관계

`30_RAG_챗봇_단계별구축`에서 이 최소 검색·생성 구조를 문서 업로드, 테스트, Judge와 교정 Agent가 있는 프로젝트로 확장합니다.

## 이어서 학습하면 좋은 내용

- 검색 문서 수와 청크 크기를 바꾸며 답변 근거의 변화를 기록합니다.
- 답변에 사용한 문서 제목이나 조각을 함께 반환하도록 출처 표시를 추가합니다.
