# 실습 상태

- 상태: **기초 단계 학습 완료**
- 강의 제목: 생성형 AI 문서 처리 확장 실습
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 학습 흐름: 생성형 AI 문서 처리
- 학습 수준: 초급

## 실습 요약

PDF 텍스트 추출, 머리말·꼬리말 전처리와 LLM 요약 결과 저장을 연습하는 실습입니다.

## 이 단계의 완료 기준

- PDF 원문 추출과 머리말·꼬리말 제거 전처리의 결과 차이를 확인할 수 있습니다.
- `_OUTPUT/historical`의 원문 텍스트와 모델별 요약본을 비교해 요약 파일이 만들어지는 전체 흐름을 설명하면 완료입니다.

## 후속 실습과의 관계

PDF 전처리와 요약 결과 저장까지를 다루는 독립 문서 처리 실습입니다. 음성 인식 실습과 직접 이어지는 파일이나 실행 흐름은 없습니다.

## 이어서 학습하면 좋은 내용

- 표·다단 문서처럼 추출이 어려운 PDF를 추가해 전처리 한계를 기록합니다.
- 같은 문서를 서로 다른 모델과 프롬프트로 요약해 누락·왜곡 여부를 비교합니다.

## 폴더 구성

- `README.md`: 실습 개요와 실행 안내
- `src`: 코드와 단계별 실습 자료
- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
