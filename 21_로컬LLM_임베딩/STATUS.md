# 실습 상태

- 상태: **기초 단계 학습 완료**
- 강의 제목: 로컬 LLM과 임베딩 확장 실습
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 학습 흐름: 로컬 LLM과 임베딩
- 학습 수준: 중급

## 실습 요약

로컬 모델 챗봇과 BGE-M3 임베딩을 실행해 외부 API 방식과 비교하는 실습입니다.

## 이 단계의 완료 기준

- 로컬 Llama 계열 모델에 메시지를 전달해 응답을 생성하는 환경과 외부 API 방식의 차이를 설명할 수 있습니다.
- BGE-M3 임베딩으로 문장을 벡터화하고 유사한 문장과 다른 문장의 거리 차이를 확인하면 완료입니다.

## 후속 실습과의 관계

로컬 추론과 임베딩 모델 사용법을 확인하는 독립 실습입니다. RAIT 품질평가와 직접 공유하는 실행 파이프라인은 없습니다.

## 이어서 학습하면 좋은 내용

- CPU와 GPU 환경에서 응답 시간과 메모리 사용량을 비교합니다.
- 한국어 유사 문장·반대 의미 문장·고유명사 문장으로 임베딩 검색 품질을 점검합니다.

## 폴더 구성

- `src`: 코드와 단계별 실습 자료
- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
