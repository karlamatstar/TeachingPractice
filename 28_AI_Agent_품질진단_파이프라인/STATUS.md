# 실습 상태

- 상태: **파이프라인 구조 학습 완료**
- 강의 제목: AI Agent 품질 진단 프로젝트(1)
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 강의 순서: 2026-06-23 · 19일차
- 학습 수준: 중급

## 실습 요약

서비스 응답 생성, 자동 평가, 테스트 케이스 생성과 최종 보고서 생성을 연결하는 실습입니다.

## 이 단계의 완료 기준

- 테스트 케이스별로 서비스 Agent를 호출하고 Judge 평가를 붙이는 실행 순서를 추적할 수 있습니다.
- 테스트 케이스 생성·평가 결과가 `_OUTPUT/final_report.json`과 `final_report.md`에 같은 내용으로 저장되는지 확인하면 완료입니다.

## 후속 실습과의 관계

`29_시간챗봇_평가리포트_자동화`는 이 품질진단 흐름을 시간 챗봇에 좁혀 CSV 저장, 실패 재실행과 버전 보고서 갱신까지 자동화합니다.

## 이어서 학습하면 좋은 내용

- JSON과 Markdown 보고서의 테스트 ID·판정·사유가 일치하는지 자동 검증합니다.
- 서비스 오류와 Judge 오류를 별도 상태로 기록해 품질 실패와 구분합니다.

## 폴더 구성

- `README.md`: 실습 개요와 실행 안내
- `src`: 코드와 단계별 실습 자료
- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
