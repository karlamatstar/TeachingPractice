# 실습 상태

- 상태: **분류 평가 구조 학습 완료**
- 강의 제목: 라우팅 분류 품질 실습
- 전체 과정: AI 기반 소프트웨어 테스터(QA) 및 모니터링 실무 과정
- 학습 흐름: 라우팅 분류 품질 평가
- 학습 수준: 중급

## 실습 요약

요청 라우팅 분류기의 예측 결과와 품질 지표를 평가하는 실습입니다.

## 이 단계의 완료 기준

- 훈련 데이터로 스포츠·타이머·주문·일반 대화 라우팅 분류기를 만들고 모델 파일로 저장할 수 있습니다.
- 테스트 정확도·분류 보고서·혼동행렬과 엣지 케이스 오분류가 `_OUTPUT/reports`에 기록되면 완료입니다.

## 후속 실습과의 관계

요청 라우팅 분류기의 학습·평가·엣지 테스트로 완결되는 독립 ML 품질 실습입니다. A/B 모델 답변 배포 판정과는 평가 대상이 다릅니다.

## 이어서 학습하면 좋은 내용

- 혼동이 많은 클래스 쌍을 기준으로 학습 문장과 엣지 데이터를 보강합니다.
- 전체 정확도 외에 클래스별 재현율과 운영상 치명적인 오분류를 배포 기준에 포함합니다.

## 폴더 구성

- `README.md`: 실습 개요와 실행 안내
- `src`: 코드와 단계별 실습 자료
- `_DOCS`: 설명·계획·설치 안내
- `_OUTPUT`: 결과·로그·리포트
